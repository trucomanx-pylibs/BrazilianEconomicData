# brazilian_economic_data

A Python package for accessing Brazilian economic indicators and government bond market data through public APIs and official data sources.


## Install from PYPI

The homepage in pipy is https://pypi.org/project/brazilian_economic_data/

```bash
pip install --upgrade brazilian_economic_data
```

## Install from source
Installing `brazilian-economic-data-info` program

```bash
git clone https://github.com/trucomanx-pylibs/BrazilianEconomicData.git
cd BrazilianEconomicData
pip install -r requirements.txt
cd src
python -m build
pip install dist/brazilian_economic_data-*.tar.gz
```

## Uninstall

```bash
pip uninstall brazilian_economic_data
```
