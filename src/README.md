# brazilian_economic_data

A Python package for accessing Brazilian economic indicators and government bond market data through public APIs and official data sources.

## 1. Installing

To install the package from [PyPI](https://pypi.org/project/brazilian_economic_data/), follow the instructions below:


```bash
pip install --upgrade brazilian_economic_data
```

Execute `which brazilian-economic-data-info` to see where it was installed, probably in `/home/USERNAME/.local/bin/brazilian-economic-data-info`.

## 2. Examples

To see some examples, visit the [example](https://github.com/trucomanx-pylibs/BrazilianEconomicData/blob/main/example) directory.

## 3. More information

To see the package information:

```bash
brazilian-economic-data-info
```

For more information, visit the [doc](https://github.com/trucomanx-pylibs/BrazilianEconomicData/blob/main/doc) directory.
